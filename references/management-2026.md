# 2026博士生项目：G0401 / G0405五部分准备指南

核验日期：2026-11-13。对象为青年学生基础研究项目（博士研究生）。下文分别标注“官方规则”“校内安排”“准备建议”；建议不是基金委评分表，也不是可直接提交的申请书。

## 先选准管理口

2026申请代码表中，**G0401为公共管理与公共政策，G0405为公共卫生管理与政策**，均属于G04宏观管理与政策。以当年代码表和申报系统为准，不沿用旧版学科网页的简称。[2026官方代码表](https://www.nsfc.gov.cn/p1/2931/3971/4002/99887.html)

以下是依据学科定位形成的选口建议，不代表预先认定某题目能被受理：

| 判断维度 | G0401 公共管理与公共政策 | G0405 公共卫生管理与政策 |
|---|---|---|
| 核心问题 | 公共组织、政府治理、政策工具与执行等管理机制 | 公共卫生服务、卫生治理、资源配置或健康政策等管理机制 |
| 需要讲清 | 制度或激励如何影响组织、行为、执行或公共服务结果 | 政策或服务体系如何影响供给、利用、质量、公平或健康结果 |
| 选口自检 | 去掉具体领域名，理论问题是否仍是公共管理问题 | 公共卫生制度与服务机制是否是解释主线，而不仅是研究场景 |
| 主要风险 | 只列现状、问题和对策，缺少可检验机制和科学方法 | 实际研究疾病病理、临床疗效或护理，管理与政策仅出现在标题 |

政策评估、DID、结构模型、实验、调查、案例研究等只是方法选项。选择方法应由问题和证据决定；没有依据要求所有项目使用某一种方法。医保、医院、药品、健康经济主题还需对照G0406医药管理与政策、G0313人口劳动与健康经济等相邻代码，不能只因对象涉及健康就固定投G0405。

管理学部的一般方向是研究管理与经济活动的规律，强调科学问题与理论、方法创新。对博士生项目，准备的中心应是：**本人提出什么新问题、用什么证据回答、为什么能够独立完成**。导师平台可以提供条件，但不能代替本人的研究贡献。

**学部通用规则还需逐项核对：**不受理纯人文社会科学或其他科学部已明确覆盖领域；避免实质相同内容重复申报或资助；真实披露前期项目及新增研究边界。涉及国家社科基金的申请人还须核查管理学部联合限申要求：2021年1月1日后作为负责人获资助、截止前尚无结项证书，以及2026年同年作为负责人申报国家社科项目等情形，均应结合指南所列例外和专项通知由依托单位确认；不能自行推定博士专项豁免。指南另有近期获资助负责人再次申请从严、部分项目结题绩效衔接等条款，适用类型不能扩大。[管理科学部2026注意事项](https://www.nsfc.gov.cn/p1/2931/3971/3975/3990/glkxb22222.html)

**G0405的明确边界：**管理三处指南将某类疾病的病理、临床及护理研究排除出公共卫生管理与政策资助范围，并指向医学科学部相关代码。使用患者数据本身不等于被排除，关键仍是核心科学问题。G04要求目标集中、方法规范、技术路线清楚。前述选口建议须放在这一官方范围内理解。[管理科学三处2026指南](https://www.nsfc.gov.cn/p1/2931/3971/3975/3990/4039/glkxsc222.html)

全国专项通知已经明确管理科学部在可选学部中。该通知为基金委计划与政策局2026-07-23文件，本轮取得的是上海交大官网公开的六页扫描件；其中试点单位名称及推荐名额留空，不能据此认定任意学校有资格或推算具体学校名额。[全国专项通知，第1、3页](https://me.sjtu.edu.cn/YanJS/upload/6-WJTZ.pdf)

## 一、时间线：先锁定校内入口，再等专项评审通知

2026年的实际安排须区分学校预遴选、院系推荐、系统提交和基金委评审。1月年度通告中的3月集中接收时间不能直接套用博士生专项。[基金委2026年度通告](https://www.nsfc.gov.cn/p1/3381/2824/99667.html)

| 2026节点 | 已取得的依据 | 对申请人的含义 |
|---|---|---|
| 5—6月：部分学校预遴选 | 湖南大学5月29日通知、6月30日前学院汇总；当时仍等待正式通知 | 提前核资格、导师同意与选题；这不是全国截止日 |
| 7月23日：全国专项通知落款 | 基金委计划与政策局通知，第6页 | 按专项通知、本校工作安排和系统最终字段准备 |
| 7—8月：部分学校组织推荐 | 华工7月28日通知、8月20日前报材料；西电电子工程学院8月18日收件 | 校内截止通常早于系统提交；不能等到全国截止才联系院系 |
| 8—9月：校内遴选 | 西电安排8月19—21日院内评审，随后公示、校级审核 | 校内答辩与基金委会评分开准备，按各自通知调整材料 |
| 9月14日前：全国推荐名单报送 | 全国专项通知第5页：依托单位完成推荐、报推荐人员名单 | 这是单位报送节点，个人须赶在更早的院系/学校截止前完成 |
| 9月14日至10月10日：全国系统申报窗口 | 全国专项通知第5页：开账号、在线填写、经依托单位审核提交 | 文件没有给具体时刻，不自行补写16:00；西电10月9日提交是校内提前安排 |
| 系统提交后：审查、函评、会评 | 具体日期、入围名单及答辩要求以基金委或学校转达的当轮通知为准 | 本轮未核得G0401/G0405统一会评日期，不把往年12月结果当今年保证 |
| 2027年起：拟执行期 | 华工2026通知列2027-01-01开始，两年或三年 | 2026申报与2027执行是两个年份字段，在校期要覆盖执行期 |

来源：[全国专项通知，第5页](https://me.sjtu.edu.cn/YanJS/upload/6-WJTZ.pdf)、[湖南大学](https://kyy.hnu.edu.cn/info/1066/10784.htm)、[华南理工](https://www2.scut.edu.cn/ist/2026/0728/c29198a633123/page.htm)、[西电电子工程学院](https://see.xidian.edu.cn/info/1053/104361.htm)。这些是通知公布的计划，未核验各节点实际执行回执。华中科技大学/同济医学院2026专项校内期限本轮尚未确认。

以2026-11-13为观察日，上述全国申报窗口和学校推荐日期已过去。已经提交者应核查本人系统状态；如收到会评答辩通知，再按通知准备。尚未申报者应向学校确认是否还有正式补充安排，并为下一年度准备，不能默认仍能补报，也不能把2026日期平移成2027正式日程。

**个人倒排建议：**校内最早截止D前8周完成选口与科学问题；D前6周整理代表成果、数据条件与独立贡献；D前4周完成本人初稿及方法核查；D前2周进行导师审阅与模拟答辩；D前3天核对签字、附件和系统回执。收到会评通知后再按确切时长重排PPT。

## 二、代表作：证明本人贡献与项目可行性

**不要把材料栏位的上限当成资格下限。**管理学部通用指南对代表性论著的发表状态有规定，但博士生专项的数量、年限、附件栏位必须再核对当年专用模板和系统。现有证据不能支持“G0401/G0405博士生必须5篇论文”或“必须某分区、一作若干篇”的说法。

已读全国2026专项通知未设统一代表作篇数；上交机动学院公开的代表性成果表允许增删行，也不能推导“博士专项限3篇”。目前应把学部通用要求、校内汇总表和系统最终栏位分别检查。

具体差别是：学部通用指南要求所列代表性论著已公开发表（含在线）；上交校内成果表则收第一/共同第一/学生一作的发表或录用论文。后者是校内候选人材料口径，不能拿“录用即可”替代最终申报要求。[上交校内成果表](https://me.sjtu.edu.cn/YanJS/upload/5-DBCG.xlsx)

2026年度通告要求论文署名、作者排序及本人贡献真实准确；简历代表性论文需按规定提供公开发表的全文PDF。共同一作、共同通讯、按姓氏排序等应保留真实标识。投稿、返修、录用、在线发表和正式刊期要分开，不能把“已投稿”写成“已发表”。[2026年度通告](https://www.nsfc.gov.cn/p1/3381/2824/99667.html)

**准备建议：**先选最能证明当前项目所需能力的成果，再在允许数量内排序。每项成果做一张证据卡：

| 字段 | 要回答的问题 |
|---|---|
| 成果及状态 | 题名、DOI或公开链接、发表日期、真实署名、PDF是否一致 |
| 本人贡献 | 问题设计、数据获取、分析、方法、写作分别由谁完成，有何可核对证据 |
| 已解决的问题 | 用一两句说明具体发现，避免只报期刊和影响因子 |
| 对本项目的作用 | 支撑哪个研究任务、数据条件或方法能力，仍有什么没有解决 |
| 与导师/博士论文的关系 | 延续什么、拓展什么、哪些研究与经费没有重复 |

G0401可突出本人识别的组织或政策机制及其可推广边界；G0405可突出卫生政策机制、服务体系证据、数据质量及相关伦理/授权。没有贴题论文时，如实呈现真实的预研究、可用数据和方法能力；这些是否可填入“代表性成果”栏仍按模板，不擅自把未发表材料包装成代表作。

## 三、PPT：用有限时间把证据讲清楚

本轮未核实G0401/G0405博士生项目全国统一的汇报分钟数、页数、字体或匿名规则。学校的10分钟选拔答辩要求不能自动当成基金委会评要求。

实际校内材料存在差异：上交机动学院公开PPT须知为5分钟、16:9；西电与西交通知的校内汇报为10分钟。湖南大学通知在交叉学部相关括注中提出不出现导师姓名，具体适用范围应向学校确认；另有学校预选模板保留导师姓名栏。因此，时长、比例和匿名信息都应绑定具体阶段及通知。[上交校内PPT须知](https://me.sjtu.edu.cn/YanJS/upload/4-PPT.pdf)、[西交校内安排](https://hsce.xjtu.edu.cn/info/1035/14449.htm)

正文模板同样有版本差异：HNU/SCUT公开参考附件仍为“建议8000字以内”，西电一般模板为“原则上不超过30页”。这些都是前期参考，提交时以当轮系统及学校最新要求为准，不混用两套提纲。

**建议的叙事顺序（不是官方模板）：**

| 模块 | 主讲内容 | 建议时间占比 |
|---|---|---|
| 科学问题 | 一个明确问题、已有解释的缺口、为什么值得研究 | 20% |
| 理论与机制 | 核心机制图或概念框架、可检验判断、与已有工作的差异 | 20% |
| 研究方案 | 任务—数据—方法—预期证据对应关系，关键识别假设 | 30% |
| 前期基础与独立性 | 本人代表成果、已取得数据/结果、与导师项目的边界 | 20% |
| 风险与收束 | 失败点、替代方案、周期内能交付什么 | 10% |

例如，只有在通知明确“汇报10分钟”时，才可按上述比例试排2/2/3/2/1分钟；若有指定结构则先服从指定结构。页数由可读性和实测时长决定，不为了凑页堆字。

准备正文和备用页两层。正文保留关键判断及证据；备用页放样本构成、变量定义、模型假设、替代解释、数据授权、伦理流程和代表作贡献细节。G0401若主张结论可推广，应说明超越地方个案的条件；G0405若涉及政策与健康结果的因果关系，应说明作用路径及混杂因素。涉及学校、导师署名的展示，先查当轮是否匿名。

## 四、函评：让申请书在没有现场解释时也能成立

全国2026专项通知第3—4页明确：先审资格、规范性与完整性，经初审受理后，由基金委统一组织通讯评审与会议评审。文件未公布G0401/G0405的固定专家数、评分权重、函评等级组合或上会分数线；不借用青C管理办法补齐。[全国专项通知](https://me.sjtu.edu.cn/YanJS/upload/6-WJTZ.pdf)

以下为**自查问题**，不是评审内部标准：

1. **问题是否清楚？**标题、摘要、目标和研究内容是否都指向同一核心问题？现实问题如何转化为可研究的机制或理论问题？
2. **创新是否可辨认？**和最接近的既有研究比较，新增解释、数据证据或方法是什么？“首次在某地研究”“用了新软件”本身不足以说明学术贡献。
3. **证据能否回答问题？**数据能否取得，观测单位、样本、比较关系和误差如何处理？提出因果结论时，要说明识别假设及检验；描述研究不能在结论中突然变成因果断言。
4. **本人能否完成？**前期成果与任务一一对应，独立工作有证据，范围与2—3年研究期相称。
5. **边界是否诚实？**与博士论文、导师项目、其他资助的关系清楚；尚未获批的数据、伦理和合作条件没有写成已取得。

G0401重点自查治理概念是否被清晰定义、机制与替代解释能否区分；G0405重点自查服务利用的选择偏倚、政策执行差异、健康结局时滞及公平性定义。不是每个项目都须采用这些变量或检验，应依研究问题取舍。

可以请一位本领域同学和一位邻近领域同学分别阅读：前者检查方法与文献漏洞，后者检查问题能否被准确复述。任何模拟评价只用于修改，不能据此预测函评分数或保证入围。

## 五、会评：把本人能力、创新边界与可行性讲透

全国通知确认会议评审，但未规定所有申请人均须参加现场答辩。**只有收到针对本人或本轮项目的答辩通知后，才据此确定出场、线上/线下、时长和材料。**以下为可能需要汇报答辩时的准备建议。

先区分校内推荐会、基金委会评和获批后学术交流会；名称中有“汇报会”不等于资助评审。管理科学部2026年青年学生项目交流活动可证明该部确有博士生项目，但不能作为2026新申请者的会评日程。[中央财经大学官方活动报道](https://int.cufe.edu.cn/info/1043/3930.htm)

复旦官方个案报道记录了首批申请者的通讯评审和现场答辩经历。这只能证明当次经历，不能把其中专家人数、评议份数、地点或月份当全国固定规则。[复旦公共卫生安全重点实验室报道](https://healthsafety.fudan.edu.cn/a/2458)

**建议重点演练的问答：**

| 问题 | 回答时需要的证据 |
|---|---|
| 为什么投G0401/G0405，而不是相邻代码？ | 研究对象、核心机制、拟贡献的知识与当年资助领域之间的对应 |
| 最重要的新东西是什么？ | 与最近研究的一项明确差异及其可检验性，避免罗列口号 |
| 这是谁的想法？你独立做什么？ | 本人贡献、导师支持范围、已有成果和拟研究任务的对应 |
| 数据拿不到或关键假设不成立怎么办？ | 已确认条件与待落实条件分开；有能保住核心问题的替代设计 |
| 为什么不是博士论文/导师项目的重复资助？ | 内容、目标、数据使用、经费及预期新增贡献的具体边界 |
| 为什么这个发现能推广？ | 机制成立的条件、异质性及不能外推的边界 |

回答可用“先给结论—提供一条证据—说明限制/补救”的顺序。没有数据就说尚未取得；无法现场确定时说明核验方法，不临时编造。正式通知若允许补充材料，按规定准备；不要假定可以在会评临时换题、追加成果或修改已提交申请。

## 五部分的交付核对表

- 时间线：一张注明学校、年度、正式/预计状态及来源的日历。
- 代表作：允许数量内的真实成果清单与本人贡献卡。
- PPT：按实际通知制作、实测不超时的主讲稿和备用页。
- 函评：科学问题—创新—方案—基础—风险的对应检查表。
- 会评：围绕选口、独立性、证据和失败预案的问答记录。

尚需个人所在单位确认：发给本校的通知版本及名额、系统最终字段、校内最终截止、当轮会评安排、匿名与PPT格式、代表性成果可列范围。数据和日期的缺口不以网上经验补成硬性规则。
