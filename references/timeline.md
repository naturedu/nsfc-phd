## 个人倒排模板（建议，非官方期限）

用所在单位确认的最早实际截止日D倒排，若D未确定保留相对日期，不填猜测日期。

| 相对时间 | 准备成果 |
|---|---|
| D前8–12周 | 核实资格与当年模板，确定本人科学问题、导师沟通及支撑条件 |
| D前6–8周 | 形成本人研究逻辑、证据清单、前期成果与可行性审查 |
| D前3–4周 | 导师与同学审阅，解决假设、方案、创新和研究基础不对应之处 |
| D前1–2周 | 逐项对照正式提纲与附件要求，核对文献、贡献、签字及伦理材料 |
| D前2–3天 | 预留系统提交与校内退回修改时间，保存提交回执 |
| 收到答辩通知后 | 按实际时长和形式制作本人汇报，计时演练并准备跨专业问题 |
| 收到结果后 | 保存官方通知；获批按实际要求填计划书，未获批按评审意见复盘 |

更新格式：event_date、date_precision、project_year、institution、stage、source_url、evidence_level、is_official_deadline、notes。日期冲突保留两条来源并核对版本，不静默覆盖。
